DYNAMIC ARRAYS
- When using static arrays i had to specify the size.
- We have a pointer telling us the length of the array.
- We can push and pop values, we push and pop from the end on a dynamic array. 
- When our array is full, we allocate a new array, so we have a new array of new size.
AMORTIZED COMPLEXITY
- Each time we need more space on a dynamic array we end up doubling the space. 
- We dont really care about constants when talking about time complexity, e.g (2 x n) can be simplified to O(n)
- The i-th element refers to an element store on a sequence e.g an array or a dataset 

CONCATENATION OF AN ARRAY 

- This is basically adding the array to itself
	ONE ITERATION SOLUTION 
	 n = len(nums)
        ans = [0] * (2 * n)
        for i, num in enumerate(nums): 
            ans[i] = ans[i + n] = num 
        return ans

	TWO ITERATIONS SOLUTION
	 ans = []
        for i in range(2): 
            for num in nums: 
                ans.append(num)
        return ans

STACKS

- Four main operations 
    - Push will add an element to last position of the stack 
    - Pop will remove the last element of the stack 
    - Peek/top will show the last element without deleting it 
        All this operations are excecuted in constant time operation 
    - Stacks are dynamic arrays, stacks are just one commnon usage of arrays
