STRINGS

Strings are very similar to arrays. 
Questions where i have to build a result string have better ways to solve it. 
	Brute force solution: 
	result = ""
	for char in chars: 
		result += chars				#This is an o(n^2)solution 

	Better way to solve this 
	result = []
	for char in chars: 
		result.append(char)
	return "".join(result) 	       #This is an o(n) solution

	Questions like Find substrings, anagrams and return substrings that match a pattern (These question are hidding a patern, therefore are not a brute force solution type of question)
